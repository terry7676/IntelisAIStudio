# Phase 1 Scope

## Built Now

1. Local project structure.
2. SQLite persistence.
3. Ollama chat streaming.
4. Desktop chat UI.
5. FastAPI REST API.
6. WebSocket chat route.
7. Token-protected API routes.
8. Plugin loading.
9. Unit tests.

## Deferred To Later Phases

1. Semantic memory with ChromaDB or FAISS.
2. File reading.
3. Image analysis.
4. Video tools.
5. Audio tools.
6. Computer control.
7. Android companion app.
8. Tailscale setup.
9. Installer.
10. Automatic updates.

## Why This Phase Is Small

The project brief says not to generate the entire project at once. Phase 1 creates the base that later phases can safely extend.
